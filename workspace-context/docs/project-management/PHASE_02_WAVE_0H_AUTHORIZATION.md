# Wave 0H — Catatan izin manusia

Tanggal 2026-09-07, pengguna workspace memilih REVISION_REQUIRED_ZERO_COST_REMEDIATION, kemudian menyatakan: "anda boleh menjalankan sandbox atau engine PDF", disusul "kerjakan". Izin ini menggantikan larangan eksekusi umum pada Wave 0G untuk pengujian lokal Phase 2 yang terbatas. Persetujuan berlaku untuk user sebagai authority sementara sesuai P2-W0-ROLE-001; tidak menggantikan bukti teknis atau menerima risiko yang belum ditelaah.

- Remediasi gratis: disetujui.
- Windows Sandbox benign observation: diizinkan setelah konfigurasi konkret diperiksa.
- Engine PDF yang telah diinventarisasi: diizinkan untuk pengujian sintetis setelah prasyarat teknis scope tersebut terpenuhi.
- Dokumen asli/Production, biaya tambahan, restart, perubahan pengaturan keamanan host, distribusi/deployment: tidak termasuk.
- Agent 0 operator eksekusi tunggal; Agent 1–3 menyiapkan worktree, Agent 6–7 review independen.
- Hasil tidak boleh dianggap Phase 2 COMPLETE atau engine approved sebelum evidence tersedia.

Wave 0G tetap artefak historis. Validator yang memerlukan otorisasi selalu false hanya berlaku untuk snapshot Wave 0G, bukan aturan untuk mengabaikan izin pengguna yang lebih baru.
