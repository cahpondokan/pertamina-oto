Saat status `COMPLETE`, exit report wajib memuat timestamp/Run ID, exact scope/IDs, final branch/commit/artifact/build/digest, hasil verification, exit-gate matrix, human approvals, residual risk/open items, dan tautan evidence.

## Aturan integritas status

- Agent 1–7 tidak menulis file ini secara paralel; mereka menyerahkan status kepada Agent 0.
- Jangan menghapus riwayat selesai untuk “merapikan” status.
- Jika bukti yang sebelumnya PASS menjadi tidak valid akibat perubahan, set phase terdampak ke `BLOCKED` atau buka controlled-change record; jangan diam-diam mempertahankan COMPLETE.
- Phase 11 COMPLETE mengubah status keseluruhan menjadi `LAUNCHED_AND_HANDED_OVER` hanya bila closure manusia sudah tercatat.
