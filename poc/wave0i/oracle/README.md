# Wave 0I independent marker observer

Agent 3 / POC-PDF-001 / FEAT-PDF-005 / PRE-008. Source-only runnable implementation, not a recorded engine run. Current authority P2-W0H-EXEC-001 remains valid; Agent 0 is the sole execution operator after integrated technical review. No repeated permission request.

`observe.py` runs already acquired qpdf 12.4.1 against a hash-bound **PDFsharp 6.2.4** merge result. It collects qpdf JSON itself; it never accepts user-supplied page observations as runtime evidence. The JSON reader follows the trailer/catalog/flat page tree in order, resolves each page's content and Helvetica resource, decodes the inline base64, and accepts only the complete simple text program emitted by Wave0H's fixed generator. It compares actual marker occurrences with fixed expectations. It does not search the whole file for strings or copy expectations into observations.

This route deliberately rejects qpdf-as-merger: qpdf inspecting its own merge is not the required independent engine observation. It does not replace a renderer, validate general PDFs, prove visual fidelity, or authorize publication.

## Exact operator interface

Runtime: already available Python 3.12+ and the already acquired Windows x64 qpdf 12.4.1 binary/runtime closure; no pip, restore, build or acquisition by this lane. Stage `observe.py` in the guest. `test_observe.py` is host preparation validation only and need not be staged. The observer has no dependency on the test fixture or Wave0H files at runtime.

Prepare one root-controlled `binding.json` per case with **exactly** these fields:

| Field | Contract |
|---|---|
| `schema` | Integer 1, never boolean |
| `case` | AB, CAB, AA or AC |
| `merger` | Exact string `PDFsharp/6.2.4` |
| `sourceSha256` | Object with exactly A, B, C, each a lowercase SHA-256 from the frozen pre-merge source ledger |
| `outputSha256` | Lowercase SHA-256 of the quarantined completed merge output recorded by root |
| `qpdfFiles` | Object mapping every staged qpdf bundle filename to its lowercase SHA-256; flat directory, executable/DLL files only; qpdf.exe and qpdf30.dll required; maximum 20 files |

Root must derive tool hashes from the admitted exact archive/member inventory, not merely trust arbitrary files selected at invocation. Parent acquired archive: `qpdf-12.4.1-msvc64.zip`, SHA-256 `3cd016cd433ef7232e42f4c13348a49cc14907a3c7278ef4f99120593126f7a6`. This archive hash is provenance context, not a substitute for exact member verification. Agent2/root binds the existing selected members and Microsoft runtime closure. Keep notices outside the minimal executable directory. No additional runtime is acquired here.

Hash and retain the binding bytes in the root evidence ledger separately from the mutable guest. The source hashes must originate **before merge**, even though the combined binding includes the later output hash. Freeze the observer script hash and record actual PDFsharp command/tool hashes in the same ledger. `merger` is an operator assertion checked against a fixed supported value, not authenticated proof of what ran. Root must match it to the actual merge receipt; changing an input JSON field cannot create engine independence.

Invoke from the supervised private guest using PowerShell variables holding the measured/staged paths and binding digest:

```powershell
& $PythonExe -B $ObserverScript --binding $BindingFile --binding-sha256 $BindingSha256 --bundle $QpdfBinDirectory --sources $SourceDirectory --output $MergedOutput --evidence $NewEvidenceDirectory
if ($LASTEXITCODE -ne 0) { throw 'OBSERVER_REJECTED' }
```

`--sources` contains A.pdf, B.pdf and C.pdf. `--bundle` contains exactly the files named in qpdfFiles, no subdirectories or extra files. `--output` must already exist and cannot alias a source. `--evidence` must not exist; its parent must exist. Failed runs may leave quarantined raw capture; never reuse them or present them as success.

The concrete child commands generated by the observer are:

```text
qpdf.exe --version
qpdf.exe --json-output=2 --json-stream-data=inline --decode-level=generalized <hash-bound-output.pdf>
```

Paths are passed as individual arguments with `shell=False`. Each child has a 15-second soft deadline, 50-ms output-size polling, direct-child kill and up to 5-second reap. Child environment retains only SystemRoot/WINDIR, System32 PATH and private guest TEMP/TMP; no inherited user PATH or qpdf environment overrides. Raw stdout is capped at 1 MiB and stderr at 64 KiB with final rechecks. Exit 3/warnings, nonzero exit, nonempty stderr and empty/whitespace stdout are rejected. No raw exception/path is printed by CLI failure handling.

These polling/size checks are **not hard memory/disk/process-tree containment**: a burst can exceed the capture limit between polls, and a killed or interrupted Python parent cannot enforce its own timer. Agent1/root's outer guest/process supervision is mandatory; allow at least the two child deadlines plus cleanup and bounded hashing, with an explicit close strategy. No claim of actual timeout, guest containment or effective network isolation is made from mocked tests. Run only the admitted fixed benign corpus in private paths; path checks do not eliminate concurrent replacement/hardlink races. Do not run arbitrary documents.

On success, new evidence directory contains version.stdout/stderr, observation.stdout/stderr, and result.json. result.json binds actual raw capture hashes, measured elapsed times, output/source/tool/script hashes, marker list and count. Result is `BOUNDED_STRUCTURAL_MATCH`, with `ROOT_LEDGER_REVIEW_REQUIRED` and `FIDELITY_NOT_ASSESSED`. Export only through Agent1/root's reviewed route. Raw error files remain private quarantine until sanitized review. Hash/retain exported evidence in the root ledger. A copied or edited result.json is not self-authenticating proof.

## Bounded profile and traceability

Sources A=2, B=3, C=1. Flat page tree, unique page object per occurrence, zero rotation, Letter media box, one decoded content stream/page, only Helvetica /F1, one exact ASCII marker text operation. Streams with residual filters, multiple streams, extra graphics/text operators, annotations, alternate font encodings, crop boxes, inherited page resources, nested page trees and unsupported structure are rejected. Unreferenced objects and document info are not a general active-content/security scan. qpdf may decode supported compression before observation; it remains a parser exposure requiring supervision.

| Case | Ordered markers | Wave0H exact ID mapping and limitation |
|---|---|---|
| AB | A-P1, A-P2, B-P1, B-P2, B-P3 | UT-MERGE-003, UT-MERGE-005; TP-MRG-001 |
| CAB | C-P1, A-P1, A-P2, B-P1, B-P2, B-P3 | UT-MERGE-004, UT-MERGE-006; TP-MRG-006, TP-MRG-008 |
| AA | A-P1, A-P2, A-P1, A-P2 | UT-MERGE-009; TP-MRG-008 |
| AC | A-P1, A-P2, C-P1 | UT-MERGE-007; TP-MRG-007 |

Every marker above has literal prefix `W0H-`. Tests compare runtime constants against the unchanged Wave0H spec. Mapping denotes supported structural assertions, **not full canonical test passes**: UT-MERGE-005 specifically requires initial A,B,C, absent from these four cases; AB supplies only related ordering evidence. Reorder/removal UI and execution-plan behavior are not exercised. TP-MRG-001 also requires no-server evidence from the environment. Independent parse contributes only the count/order/reopen assertion of TP-MRG-029; app closure and result addressability are separate. PDF001-E01/E02/E06 receive only the corresponding benign structural observations, not full experiment closure. No actual canonical ID passes during preparation.

Output compatibility with real PDFsharp bytes has not been tested yet. If the emitted structure is outside the explicit profile, stop with REJECTED and inspect bounded evidence; do not silently broaden parsing or substitute manually copied markers. General fidelity, encrypted/hostile inputs, atomic publication, large-file/performance behavior and full Phase2 portfolio remain outstanding.

This implementation's small content grammar is local code, not a general extraction capability attributed to qpdf.
