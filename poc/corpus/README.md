## Frozen specification

Version 1.0 uses deterministic JSON: ASCII, sorted object keys, compact separators,
LF terminator. Array order is preserved, including duplicate source occurrences.
The manifest digest binds expected.v1.json to manifest.v1.json. Source commit and
source-file SHA-256 must also be bound by the integrator's evidence index; seed
alone does not identify the generator implementation.

- A: two pages; B: three pages; C: one page. Fixed 612 by 792 point MediaBox,
  standard Helvetica reference, synthetic ASCII markers, no external asset.
- CONTROL_AB: five pages; ORDER_CAB: six; DUPLICATE_AA: four; REMOVE_B: three.
- Counts and dimensions define test data. They are not product limits or numeric
  performance/fidelity acceptance thresholds.
- Exact trace is in each recipe: FEAT-PDF-005; UT-MERGE-003, UT-MERGE-006,
  UT-MERGE-007, UT-MERGE-009; TP-MRG-001, TP-MRG-006, TP-MRG-007, TP-MRG-008.
- Negative observation tests support UT-MERGE-033, UT-MERGE-034 and TP-MRG-028,
  TP-MRG-029 design. They do not execute those complete product scenarios.

The schemas in poc/oracles/schemas.py are versioned, JSON Schema-compatible
subset definitions. The local validator implements only their explicit keywords;
unknown keywords, fields, versions and incorrect types reject. It is not a full
JSON Schema implementation. Frozen-manifest tests additionally detect drift in
references, recipes, digests and expected properties. A different manifest requires
review and controlled re-freeze, not merely schema validation.

PASS or publication authority. Every return has publishAuthorized=false.
The mode is fixed to SYNTHETIC_SELF_TEST so a purported real verifier record is
rejected. Markers alone, file hashes alone and reopen alone cannot prove fidelity.
Generator serialization checks are not independent parser/conformance tests.

Check structure/count/order/content, page geometry, visual preservation, and
reopen in a fresh process after candidate handles close. Validate staging bytes
and bind the published artifact to that exact digest; no replacement between
validation and publication. Missing/inconclusive evidence fails closed.
A future record version and explicit execution authorization are required.
