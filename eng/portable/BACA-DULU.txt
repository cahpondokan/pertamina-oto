PERTAMINA OTO - PAKET UJI COBA WINDOWS x64

1. Unduh ZIP sepenuhnya dari Google Drive.
2. Ekstrak seluruh ZIP ke folder lokal yang dapat Anda tulis.
3. Buka folder PERTAMINA-OTO, lalu klik dua kali MULAI-OTO.cmd.
   Jangan jalankan dari dalam ZIP. Jangan pindahkan hanya EXE.
4. Di Pengaturan, pilih folder hasil default Anda sendiri.

pengaturan sistem oleh launcher; variabel runtime hanya untuk proses ini.

Target: Windows x64, minimum versi Windows yang didukung API aplikasi
10.0.19041.0. Gunakan Windows yang masih menerima pembaruan keamanan.

komputer bersih. Komponen sistem Windows lainnya mungkin diperlukan.

perlindungan: kirim pesan error ke pengelola/IT untuk diperiksa.
