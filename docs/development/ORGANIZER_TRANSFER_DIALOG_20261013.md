# Merge → Atur halaman confirmation redesign — 13 October 2026

User requested redesign of the confirmation shown by **Atur halaman satu per satu →** when an existing Organizer arrangement would be replaced. Scope is that confirmation only; no full phase, new agent/chat, engine feature, installer activation or Production change.

## Design and behavior

The dialog follows the existing navy text, rounded white surface, amber caution, green source-file reassurance and blue safe-return action used by the new desktop design. It uses the existing **031-atur-ulang-halaman-pdf.png** Biblo (pages 3–1–2), unchanged, SHA256 `256AE41836E52D5ADED651D4A4F210F8FCA0660E5E711A9191FEB2C76DE86494`. The original `output/imagegen/` collection remains untouched; the application's existing Assets/Biblo wildcard packages its byte-identical copy.

Title: **Ganti susunan halaman?**. Explain that Merge documents replace the arrangement open in Atur halaman. Warn to save any needed result before proceeding, and reassure that original files and already saved outputs remain safe. Exactly two native actions: amber **Gunakan dokumen ini** and blue **Kembali ke Gabung PDF**. Safe initial focus is Return. There is no duplicate default ContentDialog footer. Enter/Escape are consumed through key-up, including overlapping/held keys, before safe dismissal; a click while those keys are held cannot authorize replacement. Narrow layouts stack the actions; the modal bounds/scroll to its client viewport and retains system focus visuals, automation names and high-contrast fallback.

`MergeOrganizerTransfer.cs` changes only its existing confirmation invocation to a custom view returning intent. Existing message/busy/reentrancy guards, 100 MB/1000-page validation, source ordering, rotation, atomic preparation before arrangement replacement, password handling and import/error recovery remain. The dialog never processes or deletes a document itself.
