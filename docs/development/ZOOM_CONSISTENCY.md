- Reader/editor/image preview controls use the same component. Reader plus/minus are symmetric. Reader fit page/width uses actual page dimensions; the narrow footer remains scrollable/reachable. Reader cancellation stops the zoom timer, suspended viewports do not render, and resume awaits native offset restoration before scheduling visible pages.
- History mode is explicit and independent of scale. Detail rows disable native zoom; card pinch commits once and keeps a stable row anchor. Reader zoom is separate from card size. Image/rotated fallback replaces the old height Slider with a native viewport and rotation-aware layout bounds.
- `PreviewRaster.cs` and reader/editor render changes coalesce settle updates and rerender visible images with DPI/scale-aware widths. Reader requests share 8 million pixels across retained visible/neighbor pages; editor uses 6 million, capped to 12 nearby pages. Shared image/card refresh requests share 8 million pixels for at most 24 visible images, max width 2400; reader/editor max edge 3200. Stale reader generations/editor document+scale checks/shared per-image generations reject stale results. Existing small thumbnail caches remain; this is not a claim that all historical cache allocation is now globally capped.
